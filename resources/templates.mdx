## Getting Started

All templates are available on GitHub and can be easily cloned to start your project:

```bash
# Clone any template
git clone https://github.com/nuxt-ui-templates/[template-name]
cd [template-name]

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

## Template Features

All templates include:

- **Nuxt UI v4** - Latest version with all components
- **TypeScript** - Full type safety
- **Tailwind CSS** - Utility-first styling
- **Dark Mode** - Built-in color mode support
- **Responsive** - Mobile-first design
- **Accessible** - WCAG compliant components
