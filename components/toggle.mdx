## Common Use Cases

- **Settings toggles**: Enable/disable features in user settings
- **Form controls**: Binary yes/no choices in forms
- **Feature flags**: Toggle features on or off
- **Status indicators**: Show and control active/inactive states

## Switch vs Checkbox

Use a **Switch** when:
- The change takes effect immediately
- You're toggling a feature or setting on/off
- The action is more of a state change than a selection

Use a **Checkbox** when:
- The change requires form submission
- You're selecting from multiple options
- You need an indeterminate state
